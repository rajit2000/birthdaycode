# Birthday Wish 💕

A beautiful, responsive birthday wish page created with React + Vite and Tailwind CSS.

## Features

- ✨ Beautiful gradient backgrounds and animations
- 📱 Fully responsive design
- 🎈 Floating balloons and hearts animations
- 📷 Photo gallery with modal view
- 💖 Personalized birthday message

## Setup

1. Install dependencies:
```bash
npm install
```

2. Add your photos:
   - Create a `public/photos/` directory
   - Add your photos there (e.g., `photo1.jpg`, `photo2.jpg`, etc.)
   - Update the photo paths in `src/App.jsx` if needed

3. Run the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

## Customization

- Edit the birthday message in `src/App.jsx`
- Add or remove photos by updating the `photos` array
- Customize colors in `tailwind.config.js`
- Modify animations and styles as needed

Enjoy! 🎉
